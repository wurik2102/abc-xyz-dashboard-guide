Полное руководство по дашборду анализа продаж

🎯 Назначение Sales Performance Dashboard

Дашборд анализа продаж - это ключевой инструмент для мониторинга и управления эффективностью продаж компании. Он предоставляет комплексную картину состояния продаж, выполнения планов, операционных показателей и помогает принимать обоснованные решения для роста бизнеса.

📊 Что показывает дашборд (пример анализа)

  • 💰 Продажи: XX,X МЛН руб (динамика к прошлому году)
  • 🎯 План: XX,X МЛН руб (процент выполнения)
  • 📈 Конверсия: XX,X% (эффективность продаж)
  • 💰 Средний чек: XX,X тыс руб (покупательская способность)

Ключевая особенность: Дашборд автоматически адаптируется под выбранный период - дневная детализация для коротких периодов, недельная и месячная для долгосрочного анализа.

🏛️ Архитектура дашборда анализа продаж

🎯 Концепция "Полного анализа продаж"

Дашборд спроектирован для комплексного анализа продаж на всех уровнях:

  • Стратегический уровень: Общие показатели выручки, планов, трендов
  • Тактический уровень: Операционные метрики (конверсия, средний чек, товарооборот)
  • Операционный уровень: Детализация по точкам продаж, товарным группам, периодам

📅 Управление временными периодами

🎛️ Слайсеры дат

Расположение: Правый верхний угол дашборда

📅 Начальная дата

  • Календарный селектор для выбора даты начала
  • По умолчанию: начало текущего месяца
  • Возможность выбора любой даты из доступного диапазона

📅 Конечная дата

  • Календарный селектор для выбора даты окончания
  • По умолчанию: текущая дата
  • Ограничение: не может быть раньше начальной даты

⚡ Автоматическая адаптация визуализаций

📊 Логика детализации графика

  • ≤31 день: Дневная детализация

    Пример: 01-31 июля → каждая точка = день

  • 32-120 дней: Недельная группировка

    Пример: 3 месяца → каждая точка = неделя

  • >120 дней: Месячная группировка

    Пример: год → каждая точка = месяц

🔧 Техническая реализация

Smart_Sales = IF ( DATEDIFF(MIN(Календарь[Date]), MAX(Календарь[Date]), DAY) <= 31, [Продажи_по_дням], IF ( DATEDIFF(MIN(Календарь[Date]), MAX(Календарь[Date]), DAY) <= 120, [Продажи_по_неделям], [Продажи_по_месяцам] ) )

Преимущество: Оптимальная читаемость графиков при любом выбранном периоде

💡 Рекомендации по выбору периодов

  • Оперативный анализ: 7-14 дней для контроля текущих результатов
  • Тактический анализ: Месяц для оценки выполнения планов
  • Стратегический анализ: Квартал/год для выявления трендов
  • Сравнительный анализ: Аналогичные периоды разных лет

📈 KPI карточки - Ключевые показатели эффективности

📊 Верхний ряд - Основные показатели

💰 ПРОДАЖИ

Что показывает: Общая выручка за выбранный период

Продажи_руб = SUM(продажи[Стоимость])

Сравнение: Автоматическое сравнение с аналогичным периодом прошлого года

Индикаторы:

  • 🟢 Рост к прошлому году >5%
  • 🟡 Стабильность ±5%
  • 🔴 Снижение >5%

🎯 ПЛАН

Что показывает: Плановые показатели на выбранный период

План_продаж = SUM('План продаж'[Значение])

Выполнение: (Факт ÷ План) × 100%

Цветовая индикация:

  • 🟢 >100% - перевыполнение
  • 🟡 80-100% - близко к плану
  • 🔴 <80% - недовыполнение

📊 СРАВНЕНИЕ ПО ГОДАМ

Что показывает: Многолетняя динамика продаж

Продажи_по_годам = CALCULATE([Продажи_руб], FILTER(Календарь, Календарь[год] = [Выбранный_год]))

Анализ: Показывает рост/падение по сравнению с каждым из предыдущих лет

Использование: Оценка долгосрочных трендов и стабильности роста

📊 Нижний ряд - Операционные показатели

📦 ТОВАРООБОРОТ

Что показывает: Количество проданного товара в штуках

Товарооборот_шт = SUM(продажи[Количество])

Значение: Физический объем продаж, независимый от ценовых изменений

Интерпретация:

  • Снижение → проблемы с ассортиментом/спросом
  • Рост → увеличение потока/лояльности

💰 СРЕДНИЙ ЧЕК

Что показывает: Средняя сумма одной покупки

Средний_чек = [Продажи_руб] ÷ [Количество_чеков]

Факторы влияния: Цены, покупательная способность, качество продаж

Анализ в связке:

  • ↑ Средний чек + ↓ Чеки = рост цен/премиализация
  • ↓ Средний чек + ↑ Чеки = массовость/доступность

📈 КОНВЕРСИЯ

Что показывает: Доля покупателей от общего количества посетителей

Конверсия = (Количество_чеков ÷ Посетители) × 100%

Эталонные значения:

  • 🟢 >15% - отличная конверсия
  • 🟡 10-15% - хорошая конверсия
  • 🔴 <10% - требует улучшения

🔄 ДОПОЛНИТЕЛЬНЫЕ МЕТРИКИ

Возможные показатели:

  • 📈 LFL продажи (Like-for-Like рост)
  • 👥 Количество посетителей
  • 📊 Маржинальность продаж
  • 🎯 Выполнение планов (%)

Настройка: Замените на наиболее важный для бизнеса показатель

📊 Центральный график - Аналитика продаж

📈 Трёхлинейный график динамики

Продажи (факт) - фактические продажи текущего периода
План продаж - плановые показатели
Продажи прошлый год - аналогичный период предыдущего года

🔧 Логика построения графика

Ось X: Календарь[Date] (адаптивная детализация) Продажи = Smart_Sales (умная мера с автодетализацией) План = Smart_Plan (плановые показатели) Прошлый год = Smart_Sales_Previous (SAMEPERIODLASTYEAR)

Адаптивность: График автоматически меняет детализацию в зависимости от длины выбранного периода

🔍 Интерпретация графика

🟢 Положительные сценарии

  • Фиолетовая линия выше красной: План перевыполняется
  • Фиолетовая линия выше синей: Рост к прошлому году
  • Восходящий тренд: Устойчивое развитие
  • Стабильность выше плана: Предсказуемый рост

🟡 Требует внимания

  • План не выполняется, но есть рост к прошлому году: Пересмотр планирования
  • Волнообразные тренды: Нестабильность, анализ причин
  • Сезонные колебания: Нормально, но требует учёта в планах

🔴 Критические ситуации

  • Фиолетовая ниже всех линий: Недовыполнение плана + спад
  • Устойчивый нисходящий тренд: Системные проблемы
  • Большой разрыв с планом: Нереалистичное планирование

📖 Алгоритм анализа графика

  1. Общий тренд: Определите направление движения основной линии
  2. Сравнение с планом: Оцените систематичность отклонений
  3. Годовая динамика: Сопоставьте с результатами прошлого года
  4. Точки перелома: Найдите моменты резких изменений
  5. Сезонность: Учтите календарные факторы
  6. Прогнозирование: Экстраполируйте тренды на будущее

📋 Таблица магазинов - Детальная аналитика

🏪 Показатели по точкам продаж

📊 Структура таблицы

  • Магазин: Название/код точки продаж
  • Продажи: Фактическая выручка
  • План: Плановые показатели
  • План %: Процент выполнения плана
  • Отклонение: Абсолютное отклонение от плана
  • Средний чек: Средняя сумма покупки
  • Рост YoY %: Рост к аналогичному периоду прошлого года
  • Plan_Status: Цветовой индикатор статуса

🎨 Цветовая индикация Plan_Status

  • Отлично - Выполнение плана >110%
  • Хорошо - Выполнение плана 90-110%
  • Внимание - Выполнение плана <90%

🔍 Практические применения таблицы

  • Ранжирование магазинов: Сортировка по % выполнения плана
  • Выявление лидеров: Магазины с высоким ростом YoY
  • Проблемные точки: Фокус на красные индикаторы
  • Бенчмаркинг: Сравнение показателей лучших и худших
  • Планирование: Корректировка планов на основе возможностей

⚠️ Сценарии для анализа

📈 Высокие продажи + низкий план %

Интерпретация: Магазин показывает хорошие абсолютные результаты, но план был переоценён

Действия: Пересмотр планирования, анализ потенциала точки

💰 Высокий средний чек + отрицательный YoY

Интерпретация: Рост цен компенсирует снижение количества покупателей

Действия: Работа над привлечением трафика, анализ ценовой политики

🔴 Стабильно красный статус

Интерпретация: Системные проблемы точки продаж

Действия: Глубокий анализ: локация, персонал, ассортимент, конкуренция

🚨 Алгоритм реагирования на критические ситуации

🔴 План выполняется менее чем на 80%

Немедленные действия:

  1. Анализ таблицы магазинов - выявление проблемных точек
  2. Проверка операционных показателей (конверсия, средний чек)
  3. Сравнение с прошлогодними данными
  4. Разработка плана корректирующих мероприятий

📉 Устойчивое снижение продаж >10%

План анализа:

  1. Определение: общесистемная проблема или локальная?
  2. Анализ внешних факторов (сезонность, конкуренция, экономика)
  3. Проверка внутренних процессов (ассортимент, цены, сервис)
  4. Разработка антикризисных мер

✅ Лучшие практики использования

  • Комплексный анализ: Всегда рассматривайте показатели в связке
  • Контекстное понимание: Учитывайте внешние факторы и сезонность
  • Фокус на трендах: Важнее направление изменения, чем абсолютные значения
  • Быстрое реагирование: Не откладывайте анализ критических сигналов
  • Обратная связь: Отслеживайте результаты принятых мер
  • Развитие экспертизы: Накапливайте опыт интерпретации данных
